# CodeAlpha_FileOragnizer
CodeAlpha File Organizer

About the Project

This is a Python automation project developed as part of my CodeAlpha internship.

It automatically organizes files into separate folders based on their file extensions.

Features

- Organizes image files into an Images folder.
- Organizes documents into a Documents folder.
- Organizes audio files into an Audio folder.
- Organizes Python files into a Python Files folder.
- Moves other file types into an Others folder.
- Creates folders automatically if they do not exist.

Technologies Used

- Python
- os module
- shutil module

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python file_organizer.py

5. Enter the folder path when prompted.
